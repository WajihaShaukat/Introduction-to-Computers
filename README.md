##Introduction to Computers
A computer is an electronic device that accepts raw data as input, processes it using instructions, stores the results, and outputs meaningful information. Main components of computer are hardware, and software. Computer works on four steps: 
INPUT: Entering raw data or commands through devices like a keyboard or mouse.
PROCESSING: The central processing unit calculates and transforms tha data.
STORAGE: Saving data temporarily in RAM or permanently on a hard device.
OUTPUT: Presenting the final result on a monitor, printer, or speaker.
